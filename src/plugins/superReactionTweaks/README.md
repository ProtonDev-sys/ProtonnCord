# Super Reaction Tweaks

Configure the default reaction type and animation limit.

![Screenshot](https://user-images.githubusercontent.com/22851444/281598795-58f07116-9f95-4f64-940b-23a5499f2302.png)

## Settings

- **Super React By Default:** Make the reaction picker default to super reactions.
- **Super Reaction Play Limit:** Set how many super reaction animations can play at once, or remove the limit.
