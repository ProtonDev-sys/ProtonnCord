# AppleMusicRichPresence

Shows your Apple Music activity in Discord. Requires macOS and the Music app.

![Screenshot of the activity in Discord](https://github.com/Vendicated/Vencord/assets/70191398/1f811090-ab5f-4060-a9ee-d0ac44a1d3c0)

## Configuration

Activity format strings support `{name}` for the track, `{artist}` for the artist names, and `{album}` for the album.
